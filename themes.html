PS5 Themes

Create a theme

Start the PS5 Themes payload on your jailbroken PS5. Connect from the same network and pair using the code shown on the console.

  1. Create a theme and upload a PNG, JPEG, or WebP in the Background editor.
  2. Choose the areas you want to theme. The editor converts the image to the formats your PS5 uses.
  3. Save and preview the theme, then export its ZIP from the editor’s library.
