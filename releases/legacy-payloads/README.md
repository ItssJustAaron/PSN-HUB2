# Legacy bundled payloads

These files are retained for reproducing older PSN-HUB releases. They are not
part of the current Manager download or its Payloads tab.

Use [the current PSN-HUB-Manager.elf](../../payloads/PSN-HUB-Manager.elf).
Manager 0.4.0 includes saves, USB backups, artwork operations and the pinned
advanced-save engine. Separate Save Service, Icons and Background helpers are
not needed. HENs, cheats, mod menus and emulators remain in their own library folders.
