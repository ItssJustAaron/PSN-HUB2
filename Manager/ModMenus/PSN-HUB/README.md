# PSN-HUB GTA V Menu

PSN-HUB styling for RaringM's GTA V Enhanced Story Mode menu. The patch changes the native interface and keeps upstream game version checks and controller bindings. The original MIT license and third-party notices are included here.

The build workflow applies the patch to upstream commit `7ed032cbe435869c7eb1050cef237bbefe9d5e50` and packages the universal standalone ELF with LLVM 20 and PS5 Payload SDK v0.45.

Supported game targets are PPSA04264 at 01.005.000 or 01.010.002, and PPSA04263 at 01.010.002. The PSN-HUB build requires a console test before claiming hardware compatibility.
