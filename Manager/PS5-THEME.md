# PSN-HUB PS5 theme

The artwork kit contains the purple PSN-HUB background and the HD mascot icon. Build the theme in Blaze414’s PS5 Themes editor so it can fit and encode the images to match your console’s assets. The artwork kit is a source ZIP for the editor workflow. The editor exports the finished, importable theme ZIP. [Theme format](https://github.com/Blaze414/ps5-theme/blob/main/docs/theme-format.md)

1. Extract the artwork kit. Start Blaze414’s PS5 Themes on your jailbroken console as a standalone ELF or etaHEN plugin. Open its Themes tile, or pair your phone or PC at `http://<PS5-IP>:8095` using the code shown on the console. [Installation and pairing](https://github.com/Blaze414/ps5-theme#install)
2. Create a theme named **PSN-HUB**. Under **Background**, upload `jailbreak-background.png`. Keep the default Home and Game Library areas enabled. Preview the fit before saving. [Background guide](https://github.com/Blaze414/ps5-theme/blob/main/docs/backgrounds.md)
3. Under **Home screen tiles**, assign `home-icon-hd.png` to the PSN-HUB shortcut tile. Use the icon style controls to give other tiles a matching look while keeping each tile recognisable. [Icon guide](https://github.com/Blaze414/ps5-theme/blob/main/docs/games-and-apps.md)
4. Under **Appearance themes**, choose the Control Center panel for the Appearance theme you use and try `jailbreak-background.png` as its source. Use the placement preview to keep the mascot clear of the controls. This part depends on which Appearance assets are present on the console. [Appearance guide](https://github.com/Blaze414/ps5-theme/blob/main/docs/appearance-themes.md)
5. Choose **Save → Apply**. Check the home screen, Game Library, shortcut tile, and Control Center. Once verified, export the theme from the Themes library to get the importable ZIP. Choose **No theme** in PS5 Themes to switch off its overlays.

Blaze414 reports testing on firmware 13.42 and targets firmware through 13.60. PSN-HUB’s artwork kit still needs its first console test. [Firmware support and limits](https://github.com/Blaze414/ps5-theme#firmware-support-and-known-limits)
